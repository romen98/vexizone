Правила сервера

УВАГА! Незнання правил не звільняє вас від відповідальності

1. Модифікації

1.1 - Чити (KillAura, Fly, TriggerBot і т.п.) Бан на 20 днів
1.2 - Зберігання читів на пристрої (навіть без використання) Бан на 20 днів
1.3 – Використання візуальних клієнтів (ClickPearl, ElytraSwap, AutoEat тощо: PulseVisuals, ReallyVisuals) Бан на 20 днів
1.4 - Дозволені модифікації: Badlion Client, Lunar Client, ReplayMod, Sodium, Iris, ModMenu тощо (що не впливають на геймплей) Дозволено
1.5 - Відмова від перевірки, вихід, невиконання прохань модератора Бан на 20 днів
1.6 - Признання в читах Бан на 17 днів

2. Ігровий процес

2.1 - Будування лаг-машин, шкода серверу, дюп предметів (або приховування речей) Бан по IP
2.2 - Гра на сервері з території росії (включно з рос. VPN/Proxy) Бан по IP
2.3 - Використання багів сервера у власних цілях без повідомлення адміністрації Бан на 14 днів
2.4 - Нікнейми з рекламою читів чи будь-чого (напр. Celestial197, Wexside283, YoutubeSigma165) Бан назавжди
2.5 - Пропаганда читів (зйомка відео з читами на серваку, реклама в чаті) Бан по IP
2.6 - Видавання себе за адміністрацію (Адміна, Модератора, Блогера) Бан назавжди
2.7 - Право адміністрації заблокувати за загрозу стабільності, безпеці чи економіці На розсуд
2.8 - Адміністратор romennn в цілях перевірки може порушувати правила Виключення

3.1 - Надмірна токсичність, образи гравців або адміністрації Мут на 1 день
3.2 - Образа рідних / батьків у будь-якому вигляді Мут на 7 днів
3.3 - Використання російської мови в текстовому/голосовому чаті 1-й раз: Мут 7 днів / Повторно: Бан назавжди
3.4 - Ворожі українофобські висловлювання, нацизм, фашизм, комунізм Бан по IP
3.5 - Доксинг, сватинг, загрози реальним життям Бан по IP
3.6 - Реклама сторонніх проєктів, Discord/Telegram серверів чи послуг Бан на 30 днів
3.7 - Обман гравців або введення в оману адміністрації / модерації Бан на 10 днів
3.8 - Обхід бану або муту через додаткові акаунти (твінки) Бан на 20 днів
3.9 - Продаж або купівля ігрових цінностей за реальні гроші Бан по IP
3.10 - Порушення законодавства України Бан по IP
